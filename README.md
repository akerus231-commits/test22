# ДентКальк — калькулятор себестоимости для стоматологий

Статичный сайт для стоматологических клиник с онлайн-калькулятором себестоимости и маржи услуги.
Калькулятор повторяет формулы таблицы «Себестоимость медицинской услуги — сводная форма».

## Формулы

| Показатель | Формула из таблицы |
|---|---|
| Итого прямые расходы | `SUM(C10:C17)` |
| Итого накладные расходы | `SUM(C21:C29)` |
| Накладные расходы на 1 врача | `IFERROR(C30 / C31, 0)` |
| Итого себестоимость услуги | `C18 + C32` |
| Маржа | `IFERROR((C7 - C34) / C7, 0)` |

Статьи расходов и значения по умолчанию заданы в `js/calculator.js` (`DIRECT_COSTS`, `OVERHEAD_COSTS`, `DEFAULTS`) —
чтобы добавить или переименовать статью, достаточно изменить эти списки.

## Структура

- `index.html` — страница сайта
- `css/styles.css` — стили (адаптивная вёрстка, печать в PDF)
- `js/calculator.js` — логика расчёта (без DOM, покрыта тестами)
- `js/app.js` — связь формы с расчётом, сохранение в `localStorage`
- `tests/` — тесты расчёта (`npm test`, Node 18+)

## Запуск

Сборка не нужна — откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000   # или: npm start
```

Для публикации достаточно загрузить файлы на любой статический хостинг (GitHub Pages, Netlify, Vercel и т. п.).

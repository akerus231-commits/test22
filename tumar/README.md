# Тумар (Бакай Банк) — карусели Meta Ads

5 каруселей, 27 карточек 1080×1080. Стиль — по `DESIGN.md` (снят с референсов в `refs/`),
структура — по ТЗ: обложка → категории (фото 60% + плашка 40%) → CTA.

## Файлы

- `carousels.html` — все карточки; содержание в массиве `CAROUSELS` в начале скрипта
- `export.js` — выгрузка в PNG через Playwright
- `photos/<имя>.jpg` — фото категорий (имена и описания — объект `PHOTOS`)
- `posts.md` — тексты постов
- `png/` — чистовые PNG, `png-draft/` — черновик с заглушками вместо фото

## Сборка

```bash
npm install
npm run draft    # черновик, заглушки вместо недостающих фото → png-draft/
npm run export   # чистовик → png/; падает, если нет фото или шрифта
node export.js --scale=2   # 2160×2160
```

Экспорт проверяет вёрстку и останавливается, если заголовок не помещается или текст
наезжает на карту (зазор не меньше 16 px).

## Отступления от ТЗ (решения заказчика и мои)

- **Цены и расчёты убраны** по решению заказчика: суммы из ТЗ не делятся нацело
  (4 000/6 = 666,67 и т. п.). На плашке: товар + «0% на N месяцев» (или «0% переплат»).
- «iPhone» → «Новый смартфон»: товарный знак Apple в рекламе банка без договора — риск.
- «на всё что нравится» → «на всё, что нравится» (пропущена запятая).
- Фото «Продукты» одно на 4 карусели, «Заправки» — на 3, «Стиральная машина» — на 2:
  аудитории не пересекаются, экономия генераций.

## Открытые вопросы — закрыть до запуска

1. **«3 500 партнёров».** На референсе банка — «3 500+ магазинов», в списке с сайта — 32 бренда.
   «Партнёров» и «магазинов/точек» — разные утверждения; ошибка = недостоверная реклама.
2. **«Visa Gold».** На референсах карта чёрная, обычная Visa. Если продукт не Gold — убрать с обложки.
3. **Продукты и кафе.** В списке партнёров с сайта нет ни одной продуктовой сети и почти нет кафе
   (только Mr.BBQ). Карточки «Продукты тоже по Тумар» и «Кафе и рестораны» обещают то,
   что список не подтверждает. Нужны названия сетей от банка — иначе убрать карточки.
4. **Логотипы и карта нарисованы по референсам** (символ Тумар сверен с оригиналом, но это
   аппроксимация; шрифт — Manrope вместо, вероятно, Gilroy). Для публикации нужны официальные
   SVG логотипов Bakai Bank и Тумар и рендер карты.
5. **Таргетинг по полу и возрасту.** Реклама кредитных продуктов в Meta может попадать
   в специальную категорию «Финансовые продукты», где таргетинг по полу/возрасту ограничен.
   Для Кыргызстана не проверял — проверить в Ads Manager до запуска, на этом построена вся сегментация.
